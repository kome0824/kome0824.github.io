あとがき(非公式ウディコン提出時の文章)

----------------------------------------------------------------------------------------------------
もう少しでエターなるところだったけど、一応形になって良かった。
基本システム改造ですいません。自作戦闘とか無理です…。
合成コモンは売買コモンの改造で前からあったやつをいじって終わりだったけど、
マップ名表示とか、使ったことが無いイベントの予約とか使わなくちゃダメとかで、危うく表示なしになりそうだった。
コンテストとか初めてだけど素材の表記とか大丈夫だったかな…。
ゲームのシナリオは考えるのと作るのとじゃ全然違って、原型がちょっと崩れた。
一応３部作（なんかｶｺｲｲから）の予定だけど、作れるのか…？
グラフィックとか手抜きすぎてすいません。本当にすいません。もうしませんので許して…。（って言ってもするけど…。）
音楽は…クラシックっていいよね。著作権フリーだから気負いがない。（midi製作者さんの著作権はあります。）
しかも、現代で聞いても遜色ない。むしろ良い。ポーリュシカ・ポーレ使いたかったけど著作権切れてないみたいで残念…。

ってことで、終わりです。
読んでくれた人ありがとう。
読んでない人には今度は読んでもらえるように努力します。
-----------------------------------------------------------------------------------------------------

これ以降は攻略ヒントです。
攻略に行き詰った時に読んで下さい。
（ほとんど困らないとは思いますが…）


～用語～
HP：ヒットポイント。これが無くなると戦闘不能になります。
MaxHP：最大HP。
SP：スペシャルポイント。特殊技能を使うために消費します。
MaxSP：最大SP。
攻撃：攻撃力。物理攻撃の敵に与えるダメージ量に影響します。
　　　　値が高いほど与えるダメージ量が増えます。
防御：防御力。物理攻撃の敵から受けるダメージ量に影響します。
　　　　値が高いほど受けるダメージ量が減ります。
精神：精神力。物理攻撃以外の敵に与えるダメージ量と敵から受けるダメージ量に影響します。
　　　　値が高いほど与えるダメージ量が増え、受けるダメージ量が減ります。
敏捷：敏捷性（びんしょうせい）。行動の順番に影響します。高いほど順番が早くなります。
命中率：物理攻撃の命中力に影響します。値が高いほど攻撃が命中しやすくなります。
回避率：物理攻撃の回避力に影響します。値が高いほど攻撃を回避しやすくなります。
点：お金。命はお金で買えません。（買えなくもないけど…）お金を使ってしっかり準備しましょう。


このゲームは宿屋・全快ポイントなどは基本ありません。
アイテム入手も武器・防具・道具屋はなく合成で行うか、宝箱等から入手します。
（一部買えるところもあります。決定キー押しっぱなしで連続で合成・購入できます。）
セーブ（記録）は安全な場所（街等）でしか行えません。
また、復活地点を設定しておくと全滅しても【HP・SP・点】が約半分になった状態で
その地点から始められます。場所は見ればわかると思います。
（何かが湧いてるようなところでそれに重なります。）

～はじめに～
戦闘・装備について…
１．基本属性は三すくみの状態にあります。
火（赤）＞雷（黄）＞水（青）＞火（赤）
２．防御力よりも精神力に重点をおいて装備を整えましょう。
３．無理に新しい装備をする必要はありません。
　　点を貯めて苦しくなったら一気に使いましょう。
アイテムについて…
１．点の欠片系はHPなどの割合によって回復量が変わります。
　　後半は仲間が増えるため、線の欠片系が有用です。
２．～改系の書は誰にでも覚えさせることができるので、
　　点に余裕があれば全員分買っても良いかもです。

★序盤
まずは、合成によって武器と防具を揃えましょう。
残りの点（お金）で【点の欠片】を買えるだけ買いましょう。
点の欠片は合成に必要な点と売値が同じです。
フィールドに出るとランダムでエンカウント（敵と遭遇）します。
（エンカウント率が高かったらすいません。）
最初の敵は【赤のエレメント】になると思います。
赤のエレメントが使う【ファイア】はダメージが大きいので、
なるべく高くHPを維持しておきましょう。
【迷わずの森】では宝箱の方へ向かうと帰り道が閉ざされてしまいますが、
近くに必ず出口があるので探しましょう。
（宝箱にはあまり役に立つ物は無いのでを取らなくても大丈夫です。）
Lv4ぐらいになれば迷わずの森を難なく突破できるでしょう。
迷わずの森の出口付近は色々調べると良いことがあると思います。
ものじいの家に着いたらタンスとかを漁りましょう。（基本ですね。）
ものじいに話しかけると、【森の堂ｷｰﾍﾟｰﾊﾟｰ】がもらえますが実質無くてもクリアできます。
（もらっておくと後々合成できるものが一つ増えます。）
【森の堂】に着いたら森の堂ｷｰﾍﾟｰﾊﾟｰを使いましょう。
じっと真ん中の点を見ていると気分が悪くなります。（嘘です（そういう人もいるかも…）
画面が元に戻った後も点のあった場所を見ていると、画面に色が付いたように見えます。
オプティカルイリュージョンと言うそうですがあまりうまくいきませんでした…。
その色が付いたところで赤い像が正解のスイッチになっています。
（ｷｰﾍﾟｰﾊﾟｰをみれば一つだけ違う色なので簡単に分かってしまうのですが…）
堂の中に入るとボスらしき敵がいます。（クオリティが低くてすいません…）
ボスとの戦闘ですが、HPにだけ気を付けていれば勝てると思います。（推奨レベル６）

★中盤１
東（右）の方へ進むと【マダ砂漠】に着くと思います。
ここはサボテン（に見えなかったらすいません）がある方が正解の道です。
サボテンのある方と正反対の道へ進むと宝箱があります。
最後の分岐はいままでのサボテンの配置と違う場所が正解の道です。
ここでは正解の道と正反対の道に行くとワールドマップに出てしまいます。
最後の分岐に正解すると【ツブタ】に着きます。
街の人に聞き込みをして次に進むべき場所を探しましょう。
（真ん中左側の集団の中に居ます。）
ある人に教えてもらった通りに進めばイベントです。
次は【ポロポロティー】の入手方法について街の人に聞き込みます。
（右上の方に居ます。）
【ポロポロ草】を集めるためにオアシスに向かいます。（街の右側）
【オアシス】に着いたら他と違った草の上に乗っかって調べます。
【ボロボロな草】を10本手に入れたら、戻りましょう。
街に戻ると敵が沢山いますがこちらから話しかけなければ戦いになりません。
【高貴なお屋敷】に着くとイベントです。
ポイが仲間になったので色々調べて回りましょう。
お屋敷の二階には【ファイア改の魔法書】があります。ポイに覚えさせましょう。
【ピラミッド】では二階にボスへの入口があります。（二階の右上にヒント）
（本当はもっと複雑にしたかったけど時間が…）
地下のイベントはこなしておきましょう。
【王の間】に入って話しかけると戦闘です。
敵のHPが高いので長期戦になるかもしれません。（推奨レベル１２）

★中盤２
教えてもらった通りにウナミに向かうと上の方に居るおじ（に）いさんから
カラルマの城の位置とそこに行く方法を教えてもらうことができます。
左の家の人たちには話しかけておくといいです。
一人数字を話していますがバグではありません。（携帯にでも縦読みでメモればいいんじゃない？）
（ここに行かなくても直接アイソレートケイブに向かっても大丈夫だったかも）
言われたとおりに【アイソレートケイブ】に着いたら右上の方の入口から地下へ。
地下にはテンがいて、一緒に敵と戦闘になりますが多分問題無く倒せます。
【キングランド】に着いたら名声を集めましょう。
ここで、ピラミッド地下のイベントをこなしておくと名声が１増えています。（見えませんが…）
名声は適当に話しかけていれば集まると思います。
個人的には【パピルスの紙】を5000点で売って、選択肢の問題（231）に全問正解すれば良いと思います。
ある程度集まったと思ったら、門番に話しかけましょう。
テンが仲間になりましたので装備でも整えときましょう。
灯台に着いたら、【一階：下、二階：右】の階段でボスのところです。
（ここら辺からかなり手抜きになってきてますね…。）
ボスの左の部屋には灯台守がいますのでウナミで渡されたアイテムがあればアイテム入手です。
ボスは結構簡単に倒せるかな？（ここらへん調整が難しかったから厳しいかも）（推奨レベル２１）

★終盤
ツブタ→ウナミ→カラルマの島で城に乗り込めー。
城ではブラックナイトと戦闘ですが、負けてもいいです。
勝てばそのままカラルマとの最終決戦です。（勝てるのか…？）
負けると、それぞれ分かれて塔に飛ばされます。（ここももっと複雑にしたかった…）
弱過ぎて勝てないと思ったら、敵に突っ込まずにレベル上げをしましょう。（多分勝てる）（推奨レベル２２）
各々が集まったら一旦引き返してウナミでセーブしてもいいかも。
再びブラックナイトと戦闘ですが、さっきより弱くなってるので簡単に倒せると思います。（推奨レベル２５）
ブラックナイトとの戦闘が終わるといよいよカラルマとの戦闘なので、また一旦戻ってもいいかもしれません。
カラルマは４回変身します。（変身と言葉があってない時がありますが仕様です。すいません。）（推奨レベル２８）
（半分以上のHPを残した状態から一撃で倒せるとそこで戦闘終了になります。裏技？いいえ、バグです。）
カラルマの色が戦闘時とフィールド時であっていませんが仕様です。
それで、終了ですかね。文章にすると結構短い…。
エンディングが終わったらキングランドの３連戦に挑戦してみるとか、
携帯にメモったところに行ってみるといいかも。
（本当は裏ダンジョンとか作りたかったです…。）
